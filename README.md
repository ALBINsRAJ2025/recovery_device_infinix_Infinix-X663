## 🚀 Installation Guide

<div style="background: linear-gradient(135deg, #6366F1 0%, #8B5CF6 100%); border-radius: 20px; padding: 30px; color: white; margin: 30px 0; box-shadow: 0 10px 40px rgba(99,102,241,0.3);">

### ⚡ Flash TWRP in 6 Easy Steps

</div>

<div style="background: white; border-left: 4px solid #6366F1; border-radius: 10px; padding: 25px; margin: 20px 0;">

### 📋 Prerequisites

Before you begin, ensure you have:

<div style="display: grid; grid-template-columns: 1fr 1fr; gap: 15px; margin: 20px 0;">

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ USB Cable (working)
</div>

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ Fastboot installed on PC
</div>

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ Bootloader unlocked
</div>

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ USB Debugging enabled
</div>

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ Full backup (recommended)
</div>

<div style="background: #f0f0f0; padding: 15px; border-radius: 10px; border-left: 4px solid #10B981;">
✓ Device fully charged
</div>

</div>

</div>

<div style="margin: 25px 0;">

### Step 1️⃣: Download & Prepare

Download the latest TWRP image and place it in your fastboot directory:

```bash
# Create working directory
mkdir ~/twrp-x663
cd ~/twrp-x663

# Download TWRP (from releases page)
wget https://github.com/ALBINsRAJ2025/twrp_x663/releases/download/v3.7.2/twrp-3.7. 2-x663-signed.img
```

</div>

<div style="margin: 25px 0;">

### Step 2️⃣: Enable USB Debugging

On your **Infinix Note 11**:
1. Open **Settings**
2. Go to **About Phone**
3. Tap **Build Number** 7 times
4. Go back to **Settings** > **Developer Options**
5. Enable **USB Debugging**

</div>

<div style="margin: 25px 0;">

### Step 3️⃣: Boot to Bootloader

Connect your phone to PC and run:

```bash
adb reboot bootloader
```

Or manually:
- **Power off** the device
- Hold **Power + Volume Down** buttons for 5-10 seconds
- Select **Fastboot** mode using volume buttons

<div style="background: #FEF3C7; border-left: 4px solid #F59E0B; border-radius: 8px; padding: 12px; margin-top: 12px;">
💡 The device will show "FASTBOOT MODE" on screen
</div>

</div>

<div style="margin: 25px 0;">

### Step 4️⃣: Flash TWRP

In fastboot mode, run:

```bash
# Flash recovery partition
fastboot flash recovery twrp-3.7.2-x663-signed.img

# Verify flash
fastboot getvar recovery_size
```

Expected output:
```
Sending 'recovery' (49152 KB)
OKAY [  1.234s]
Writing 'recovery'
OKAY [  0.567s]
Finished.  Total time: 1.801s
```

</div>

<div style="margin: 25px 0;">

### Step 5️⃣: Reboot to Recovery

```bash
fastboot reboot recovery
```

Or manually:
- **Power + Volume Up** during boot to enter recovery

<div style="background: #DBEAFE; border-left: 4px solid #0EA5E9; border-radius: 8px; padding: 12px; margin-top: 12px;">
ℹ️ TWRP will boot for the first time. This may take 30-60 seconds.
</div>

</div>

<div style="margin: 25px 0;">

### Step 6️⃣: Verify Installation

In TWRP recovery:
1. Tap **About**
2. Verify version shows **3.7.2**
3. Check device name shows **X663**
4. You're ready to use TWRP!  🎉

</div>

## ❓ FAQ

<div style="background: linear-gradient(135deg, #10B981 0%, #34D399 100%); border-radius: 20px; padding: 30px; color: white; margin: 30px 0; box-shadow: 0 10px 40px rgba(16,185,129,0.3);">

### Frequently Asked Questions

</div>

<details open style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #6366F1;">
<summary style="font-size: 1.1em; font-weight: bold; cursor: pointer; color: #6366F1;">
  ❓ What is TWRP and why do I need it?
</summary>
<div style="margin-top: 15px; color: #333;">
<p><strong>TWRP (Team Win Recovery Project)</strong> is a custom recovery environment that replaces the stock recovery on your Infinix Note 11.  It allows you to:</p>
<ul>
<li>Create complete system backups before trying mods</li>
<li>Flash custom ROMs and modifications safely</li>
<li>Access your device without booting to Android</li>
<li>Fix bootloops and recover from soft bricks</li>
<li>Manage files and system partitions</li>
</ul>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #8B5CF6;">
<summary style="font-size: 1.1em; font-weight: bold; cursor: pointer; color: #8B5CF6;">
  🔒 Will flashing TWRP void my warranty? 
</summary>
<div style="margin-top: 15px; color: #333;">
<p>⚠️ <strong>Yes, likely it will. </strong> Unlocking the bootloader and flashing custom recovery is considered modifying the device.  Most manufacturers will void warranty for this.</p>
<p>However, you can always re-lock the bootloader and restore stock recovery to return to warranty state (though not always guaranteed).</p>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #EC4899;">
<summary style="font-size: 1.1em; font-weight: bold; cursor: pointer; color: #EC4899;">
  🔴 Can I hard-brick my device?
</summary>
<div style="margin-top: 15px; color: #333;">
<p>Hard bricking is <strong>extremely rare</strong> if you follow the instructions.  The risk is minimal because:</p>
<ul>
<li>Recovery partition is separate from bootloader</li>
<li>Flashing recovery alone won't brick the boot partition</li>
<li>You can always re-flash from fastboot</li>
</ul>
<p>⚠️ The main risk is <strong>soft bricking</strong> (bootloop) which TWRP can help you fix! </p>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #F59E0B;">
<summary style="font-size: 1.1em; font-weight: bold; cursor: pointer; color: #F59E0B;">
  🔐 Will my data be encrypted in TWRP?
</summary>
<div style="margin-top: 15px; color: #333;">
<p>Yes! This TWRP build includes full FBE (File-Based Encryption) decryption support for Android 12.  You can:</p>
<ul>
<li>Access encrypted /data partition</li>
<li>Create backups of encrypted data</li>
<li>Restore encrypted backups</li>
</ul>
<p>ℹ️ Your data encryption password is the same as your lock screen PIN/password.</p>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #10B981;">
<summary style="font-size: 1.1em; font-weight: bold; cursor: pointer; color: #10B981;">
  📱 Can I use TWRP to unbrick my device?
</summary>
<div style="margin-top: 15px; color: #333;">
<p><strong>Yes, in most cases!</strong> TWRP can fix:</p>
<ul>
<li>✅ Bootloops (restore from backup)</li>
<li>✅ Soft bricks (re-flash system partition)</li>
<li>✅ Forgotten lock screen (factory reset via TWRP)</li>
<li>✅ Broken system app (restore from backup)</li>
</ul>
<p>⚠️ However, TWRP <strong>cannot fix</strong> hard bricks where bootloader is corrupted.  For that, you need EDL mode flashing with professional tools.</p>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #0EA5E9;">
<summary style="font-size: 1. 1em; font-weight: bold; cursor: pointer; color: #0EA5E9;">
  ⚡ Why does it take time to boot TWRP first time?
</summary>
<div style="margin-top: 15px; color: #333;">
<p>On first boot, TWRP initializes its recovery environment:</p>
<ul>
<li>Checks and mounts partitions</li>
<li>Sets up encryption/decryption</li>
<li>Initializes touch driver</li>
<li>Loads system files</li>
</ul>
<p>This can take <strong>30-60 seconds</strong>. Subsequent boots are faster.  This is completely normal!</p>
</div>
</details>

<details style="background: #f9f9f9; border-radius: 10px; padding: 20px; margin: 15px 0; border-left: 4px solid #6366F1;">
<summary style="font-size: 1. 1em; font-weight: bold; cursor: pointer; color: #6366F1;">
  🧪 How can I help test untested features?
</summary>
<div style="margin-top: 15px; color: #333;">
<p>We'd love your help!  To test untested features like screenshot or vibration:</p>
<ol>
<li><strong>Try the feature</strong> in TWRP recovery</li>
<li><strong>Document results:</strong> Does it work? Any issues?</li>
<li><strong>Enable adb logcat:</strong> Capture logs while testing
   <pre>adb logcat -b all > test_log.txt</pre>
</li>
<li><strong>Open an issue</strong> on GitHub with:
   - Feature name
   - What you tested
   - Results (working/broken)
   - Device logs attached
</li>
</ol>
</div>
</details>
